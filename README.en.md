<p align="center"><em>Preview key vocabulary from any English content before you read or watch – then dive in with confidence and context.</em></p>

**CaptiPrep = Caption + Preparation.** It helps you learn languages efficiently by turning any English content into a targeted pre‑study session. Whether it's YouTube subtitles, a web article, a highlighted selection, or text you paste in, CaptiPrep previews key words & expressions first. Then read/watch the original; the built‑in context cements memory naturally. Contextual learning becomes lighter, faster, and more fun.

## 🤔 What can it do?
### 1｜Multi-source content capture
- **YouTube subtitles**: auto-captured with multi-path extraction & self-healing fallbacks.
- **Web articles**: click the extension icon or right-click "Learn this page" to auto-extract the article body.
- **Text selection**: select any text on a page and right-click to build cards from it.
- **Manual paste**: click "+" in the panel to create content from pasted text.

### 2｜Smart filtering & flashcard generation: AI does an initial sift; you fine‑tune the selection; flashcards are generated automatically—start studying instantly. Click the speaker icon on any card to hear the pronunciation.

## ⚙️ How to use
1. Install:
- Chrome Web Store: https://chromewebstore.google.com/detail/captiprep/jgbcfnmpjaflngdajjjnlehfkfohlmfl?authuser=0
- Edge Add-ons: https://microsoftedge.microsoft.com/addons/detail/captiprep/fbfhhgelelmeopkjdihhklkcncbikjem
- Dev (local): Chrome → `chrome://extensions` → enable Developer Mode → Load unpacked → select this repo (git clone https://github.com/jeanchristophe13v/CaptiPrep.git first).

2. **Video**: open any YouTube video with subtitles and click the extension icon.
3. **Article**: open any English web page and click the extension icon, or right-click "Learn this page" to auto-extract the article body.
4. **Selection**: select some text on a page and right-click "Learn this page".
5. **Manual**: click "+" (New content) in the panel and paste text.
6. In the floating panel: extract content → select words/phrases → generate cards → study. **Arrow keys switch cards; Space favorites a word.**
7. Open the Wordbook to revisit learned items anytime; filter by source (Video/Article/Selection/Manual).
8. Export to download your collected words.
9. Model tips: set filtering model to gemini-2.5-flash-lite and card generation model to gemini-2.5-flash for a good balance.

## ❓ Why it works
- Pre‑exposure: you remove friction before reading/watching.
- Real context: examples come from the exact content—retention sticks.
- Accumulation: everything funnels into one Wordbook for spaced review.
